# Lesson 6 — From Building AI Apps to Choosing Your Career in Tech

> **Don't just use AI. Learn how to build with it, and then decide where you want to take it.**

## 1. Tech Career Landscape Has Changed

AI is changing how software is built and how many tech roles work.

It is not only creating new roles like **AI Engineer**. Existing careers such as software engineering, data science, cybersecurity, and product development are also being transformed.

```text
                    AI
                     │
          ┌──────────┼──────────┐
          ↓          ↓          ↓
      Software      Data     Product
     Engineering     & ML    & Business
```

The goal is not to chase every new AI title. Understand how your existing skills can connect with AI.

## 2. From AI User to AI Builder

There is a big difference between **using AI** and **building with AI**.

- **AI User:** Uses AI tools to solve problems.
- **AI Builder:** Creates applications that use AI to solve problems.

```text
AI User → Uses AI Tools → AI Builder → Builds AI Apps
```

The mindset changes from:

> **"How can AI help me?"**

to:

> **"What can I build with AI?"**

## 3. What Does It Take to Build an AI App?

You don't need to train a huge AI model from scratch to build an AI application.

A typical AI app looks like:

```text
User Interface
       ↓
Application Logic
       ↓
AI Model / API
       ↓
Data / Tools
       ↓
Useful Output
```

Useful skills include:

- Programming
- APIs
- Prompt engineering
- Data handling
- AI/ML fundamentals
- UI development
- Testing
- Deployment

The important part is understanding how these pieces work together.

## 4. Build Projects That Prove Your Skills

Saying **"I know RAG"** is less powerful than showing a project where you actually used it.

For example:

> **I built a document Q&A system using RAG.**

For every project, ask:

- What problem did I solve?
- Why did I use AI?
- How did I build it?
- What technologies did I use?
- What did I learn?

Your portfolio should show **what you can do**, not just what you have studied.

## 5. There Is More Than One Career Path

AI does not lead to just one career.

| Career Path | Main Focus |
|---|---|
| **AI Engineer** | Build AI-powered applications |
| **ML Engineer** | Build and deploy ML systems |
| **AI Researcher** | Develop new AI methods |
| **Data Scientist** | Analyze data and build predictive models |
| **MLOps Engineer** | Deploy and maintain ML systems |
| **Software Engineer** | Build software products and systems |

There is no single "best" path.

Choose based on what you enjoy, your strengths, and the problems you want to solve.

## 6. The Skills That Actually Matter

AI tools and frameworks change quickly. **Fundamentals last longer.**

Focus on:

- Programming
- Computer science fundamentals
- Problem solving
- Mathematics and statistics
- Machine learning
- Generative AI
- APIs and systems
- Communication

```text
Strong Fundamentals
        ↓
Explore Different Areas
        ↓
Find What You Enjoy
        ↓
Specialize
        ↓
Build Real Projects
```

Don't try to learn every framework just because it is trending.

## 7. 90-Day Tech Career Roadmap

### Days 1–30 — Foundations

Focus on:

- Python
- Git & GitHub
- CS fundamentals
- AI/ML fundamentals
- Basic mathematics and statistics

**Goal:** Build a strong foundation.

### Days 31–60 — Build

Create **2 practical projects**, such as:

- AI application
- RAG application
- ML project
- AI automation tool

**Goal:** Turn knowledge into evidence.

### Days 61–90 — Showcase & Specialize

- Improve your best project
- Document it properly
- Build your GitHub portfolio
- Share your work
- Network with other developers/researchers
- Explore your target career
- Prepare for applications/interviews

**Goal:** Become visible and ready for the next step.

```text
Days 1–30 → Learn
Days 31–60 → Build
Days 61–90 → Showcase + Specialize
```

## Key Takeaways

> **You don't need to know exactly where your career will end up. You need to start moving in a direction.**

1. AI is changing the tech career landscape.
2. Move from **using AI** to **building with AI**.
3. Projects are evidence of your skills.
4. There is more than one AI career path.
5. Strong fundamentals matter more than chasing every new tool.
6. Use projects to discover what you enjoy.
7. Build, share, network, and improve.

```text
Learn → Build → Share → Explore → Specialize → Build Again
```

> **Don't wait until you feel completely ready. Build something, learn from it, and let the experience shape your career.**
